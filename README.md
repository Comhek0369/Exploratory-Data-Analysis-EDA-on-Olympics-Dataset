## 🔍 Objective

To understand the **sales trends**, **customer behavior**, and **product performance** through data visualization and statistical summaries.

---

## 📦 Dataset

The dataset contains transactional records from an online UK-based retail store. Key features include:

- `InvoiceNo` – Invoice number
- `StockCode` – Product/item code
- `Description` – Item description
- `Quantity` – Quantity of each item per transaction
- `InvoiceDate` – Date and time of invoice generation
- `UnitPrice` – Price per item
- `CustomerID` – Unique identifier for each customer
- `Country` – Country of the customer

---

## 🛠️ Tools & Libraries

- Python 3.x
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

---

## 📈 Key Analysis Performed

- 📌 **Data Cleaning**
  - Removed nulls and duplicates
  - Filtered canceled transactions

- 🔍 **Univariate & Bivariate Analysis**
  - Histograms and boxplots for numerical features
  - Countplots for categorical features
  - Pairplots and heatmaps for correlation

- 📆 **Time Series Trends**
  - Monthly and daily sales trends
  - Seasonal patterns and outliers

- 💰 **Top Performing Products & Countries**
  - Best-selling items
  - Sales distribution across regions
